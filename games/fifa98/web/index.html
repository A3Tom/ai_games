Start the test and use arrows, W A S D or the direction buttons. Press C to carry a test ball, then B to release it towards your movement target; when standing still, it launches forwards. Choose a ground or lofted launch above. While paused, Space advances one tick.

Recovery progress

Recovered timing, player-distance, grounded target launches, ball drag and spin, player target, turning and horizontal movement arithmetic run directly as compiled C. Original stadiums, grass, ball sprites and player poses render through native drawing code. Match initialization, complete player actions, other ball contacts, AI and rules still need recovery.
